House Price Prediction Using Machine Learning

📌 Project Overview
This project explores house price prediction using Python and machine learning. It includes Jupyter notebooks for data analysis and model development, along with a simple web interface for entering housing features.

📊 Dataset
The project uses the `USA_Housing.csv` dataset. The notebook and dataset should be reviewed to confirm the exact features and target variable before drawing conclusions.

 🛠️ Technologies Used
- Python
- Jupyter Notebook
- Pandas and NumPy
- Scikit-learn
- HTML and CSS

🎯 Project Goals
- Explore and prepare housing data
- Understand relationships between housing features and prices
- Develop and evaluate a regression model
- Explore a basic web interface for house price prediction

📁 Project Files
- `fapp.ipynb` — Jupyter notebook
- `model.ipynb` — Jupyter notebook
- `USA_Housing.csv` — Dataset
- `index.html` — Web interface template
- `main.css` — Styling for the web interface
- `pf` — Model file; format and purpose to be verified
